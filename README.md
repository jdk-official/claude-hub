# hub

Terminal launcher: lists recent repos (GitHub + local), previews their state, and launches
`claude` in the one you pick. Runs in Ghostty (`ghostty -e hub`).

- Script: `bin/hub` (Python 3 + fzf + gh + git), symlinked to `~/.local/bin/hub`
- Requirements brainstorm: `docs/requirements-brainstorm.md`
