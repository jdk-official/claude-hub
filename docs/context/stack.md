# Stack

The languages, frameworks, services, and tooling this project runs on.

- Python 3 (stdlib only), single file: `bin/hub`.
- External tools: `fzf` (picker), `gh` (GitHub list/clone, SSH auth), `git`, `claude`.
- Runs in Ghostty on Arch Linux + Omarchy (Hyprland); symlinked to `~/.local/bin/hub`.
- Cache (planned): `~/.cache/hub/` (home, not the data drive).
